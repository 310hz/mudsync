# `msync manage`（同期ルール編集 TUI）

prompt_toolkit のフルスクリーンアプリ（`commands/manage.py`）。プロジェクト内のファイルをブラウズし、各項目の同期状態（[concepts/domain.md](../concepts/domain.md) の include / exclude / data）を切り替えて `msync.json` に保存する。

挙動が複雑なので、変更前に実際に操作して現状の動作を観察すること。

## 起動時の自動除外

起動時に、プロジェクト直下（再帰しない）の次の項目を `excludes` に追加する（グローバル除外と data の項目は対象外）。

- 10MB を超えるファイル
- 直下の項目数が100を超えるディレクトリ

自動除外は1項目につき1回だけ。適用した項目は `auto_excluded` に記録し、以後は自動除外しない。ユーザーが include に戻したら、その選択が保たれる。保存（Enter）しなければ `excludes` も `auto_excluded` も反映されない。

## キー操作

| キー | 動作 |
| --- | --- |
| ↑↓ / j k | カーソル移動 |
| PgUp / PgDn | 1画面分移動 |
| → / l | ディレクトリに入る |
| ← / h | 親ディレクトリへ（プロジェクトルートより上には行かない） |
| Space | include ⇔ exclude を切り替え |
| d | data を切り替え |
| Enter | ルールを整理（後述）して保存し終了 |
| Esc / q / Ctrl-C | 保存せず終了 |

## 表示

| 色 | 状態 |
| --- | --- |
| 緑 | include |
| 灰 | exclude |
| 橙 | data |

ディレクトリは配下の状態を集約して表示する。

- 配下すべて include → 緑 + 名前末尾に `*`
- 配下すべて data → 橙 + `*`
- include と data の混在 → 橙（`*` なし）
- 配下すべて exclude → 灰
- それ以外（一部 exclude） → 緑（`*` なし）

各項目の右にサイズを表示する。ディレクトリのサイズはバックグラウンドスレッドで計算し、計算中は `calc...` と出す。

## トグルの意味論

- ディレクトリをトグルすると配下すべてに効く。ルール上はディレクトリ自体のエントリ（`dir/`）を1つ追加し、配下の個別エントリは消す。
- 除外済みディレクトリ配下の1項目だけを include に戻すと、親ディレクトリのエントリを外し、その項目以外の兄弟を個別に `excludes` へ追加する（data でも同様）。
- 一部 exclude のディレクトリで Space → 配下の exclude をすべて解除（全 include）。
- data にすると、その項目に関わる exclude は外れる。data の項目で Space を押すと exclude になる。
- グローバル除外の項目は画面に出ず、トグルもできない。

保存時、ディレクトリエントリと重複する直下の子エントリを削除して `excludes` / `data_includes` を整理する（`_compact_rules`）。

## 性能上の注意

深い階層・大量ファイルのプロジェクトで起動・移動・トグルが重くなる問題があり、過去にキャッシュ（子要素・状態・相対パス）とボトムアップの状態計算で改善した経緯がある。状態キャッシュはトグルのたびにバージョン番号で一括無効化している。走査やキャッシュまわりを触るときは、大きなディレクトリで体感速度を確認すること。
